📋 Changelog

What's changed on this site, and when each course section's source file was last prepared.

Site changes

2026-07-28
Expanded the Glossary from 98 to 208 terms (verified zero duplicates) — added the full 26-letter NATO phonetic alphabet as a new section/agency ("ICAO / International Radio Alphabet"), plus 84 more terms filling out existing sections:
  • Medical Operations (+24) — the rest of DCAP-BTLS (Deformity, Abrasion, Puncture, Burn, Tenderness, Swelling), SAMPLE, OPQRST, AVPU, and GCS spelled out letter-by-letter, plus CPR/AED/Heimlich and burn classifications
  • Fire Safety & Hazmat (+8) — Backdraft, Ignition, Extinguisher, and Classes A/B/C/D/K each linking to their matching Visual Aid animation
  • Light Search & Rescue (+8) — Pancake/Lean-to/V-Void (linking to the Structural Collapse Voids diagram), Hasty/Interior/Exterior Search, Tagging, Shoring
  • CERT Organization (+8) — the remaining ICS sections (Operations, Planning, Finance) and command-staff roles (Safety Officer, Liaison Officer, Unified Command, Incident Commander, Demobilization)
  • Scene Basics & PPE (+8), Disaster Preparedness (+7), Disaster Psychology (+5), Terrorism Awareness (+4), and Field Reference (+12, including Earthquake, Tsunami, Hurricane, Tornado, Wildfire, Flood, and Pandemic tying into the new Field Reference hazard guides)
2026-07-28
Added 18 new Glossary terms drawn from the multi-agency Field Reference material (CISA, OSHA, USFA, VOAD, GDACS, NWS, and more — including RUN-HIDE-FIGHT, WATCH vs. WARNING, SDS, GHS, FLASHOVER, GO-BAG, AT-RISK, SURGE CAPACITY, and ICS), bringing the glossary to 98 terms. Added a filter so the list can be viewed three ways:
  • Alphabetical (new default) — grouped by first letter, A–Z
  • By Section — the existing course-section grouping, now with a ninth group, "Field Reference (Multi-Agency)," for terms that aren't tied to a specific course slide
  • By Agency (new) — grouped by which agency the term comes from; most of the original 80 terms default to "FEMA / CERT Basic Training"
Terms sourced from Field Reference material link to companion.html instead of a course slide, since they aren't literally covered in a CERT deck even when grouped under an existing section like Fire Safety.
2026-07-28
Moved the site search box to the home page (submits to search.html?q=, which already supported that deep link) and removed the separate "Search Everything" card from the hub grid. Also reorganized the Visual Aids gallery to group diagrams under a heading per section instead of one long flat grid, and added 4 new diagrams built in Canva that summarize the new multi-agency Field Reference material rather than a specific course slide:
  • Know Your Hazards — six hazard types from FEMA's CERT Hazard-Specific Annex
  • Run. Hide. Fight. — the CISA/DHS active-threat response framework
  • Home Fire Escape Plan — the U.S. Fire Administration's three household basics
  • Build a Kit. Make a Plan. Stay Informed. — Ready.gov/Red Cross's household-preparedness framework
Along the way, several early Canva generations for these came back with fabricated statistics, invented quotes, or icons swapped onto the wrong label — all rejected; cutting each poster down to 3–6 items (instead of 9) got clean, correctly-labeled results.
2026-07-26
Moved the CERT Basic Training Participant Manual from Field Reference to Course Materials, where it now sits as the first card above the 8 section decks. Also reformatted every Course Materials tile: title and description now sit on top, with the action buttons (Transcript/PDF/PPTX) in their own row underneath, fixing a layout bug where long section titles collided with the button row on narrower cards. Along the way, found and fixed an actual HTML bug in the manual card: it was written as an <a> tag wrapping another <a> download button, which is invalid — real browsers silently split it into a working card plus a second, empty, broken duplicate. Replaced with a <div> card (matching the pattern already used for the 8 section cards) instead. Field Reference's intro text and the home page's cards were both updated to reflect the move.
2026-07-26
Added 21 more multi-agency links to the Field Reference page, curated from a review of a much larger public situational-awareness link list (vinalcjps.com). Folded live hazard-monitoring tools into the existing categories rather than mirroring the source's own category names, and added one new category:
  • Hazard-Specific Guides — live monitors: USGS Earthquake Tracker, Tsunami Warning System, National Hurricane Center, live NWS radar, InciWeb, AirNow's Fire and Smoke Map, FEMA's Flood Map Service Center, USGS Volcano Hazards and Landslide Inventory, NOAA Space Weather, GDACS, and an NRC nuclear-facility finder
  • Fire & Utility Safety — PowerOutage.US
  • Incident Command & Coordination — National VOAD and the Census Bureau's OnTheMap for Emergency Management
  • New category, Live Situational Awareness & Local Conditions — CTRoads (Connecticut traffic), Waze, DownDetector, Broadcastify (live public-safety radio), HHS Hospital Utilization, and the HHS emPOWER Map (power-dependent Medicare beneficiaries by area)
Deliberately left out: crime/OSINT/conflict-tracking tools, a WiFi-wardriving map, aviation/marine spotting sites, and general news/trade sites — out of scope for a community CERT volunteer guide. Two source URLs had moved since the original list was published (InciWeb, HHS emPOWER Map) — updated to their current redirect targets.
2026-07-26
Expanded the Field Reference page with a new multi-agency section — curated links to official, non-CERT-specific material that complements the course, organized into six categories:
  • Hazard-Specific Guides — FEMA's CERT Hazard-Specific Annex, Ready.gov's per-hazard Information Sheets, and NOAA/NWS's Weather Safety Hub
  • Security & Active Threats — CISA's Active Shooter Preparedness pocket card and action guide
  • Worker & Rescuer Safety — OSHA's worker-safety publications and QuickCards (PPE, hazard communication)
  • Fire & Utility Safety — the U.S. Fire Administration's home fire escape plan guidance
  • Incident Command & Coordination — FEMA's free IS-315.a course on how CERT integrates with the Incident Command System
  • Family & Community Preparedness — the American Red Cross's household preparedness checklists
Every card links out to the source agency's own site (data/field-references.js) — nothing is hosted or reproduced here, and cards tagged "Complements Section N" jump straight to the related course section.
2026-07-26
Fixed rendering issues on CERT Team Command Structure and Phases of a Crisis and gave both another pass:
  • Removed the camera swing entirely on both (now static) and removed the floor plane that was showing as a stray dark bar at the bottom of frame
  • Org chart: box labels now auto-fit and center inside their box instead of overflowing the edges; connecting lines now grow into place top-to-bottom with the signal pulse riding the growing tip, instead of being static from frame one
  • Phases of a Crisis: redesigned from a radial hub layout to a square cycle with big directional arrows (Impact → Inventory → Rescue → Recovery → back to Impact) — same real CERT content (Section 7, slide 12), clearer at a glance; the traveling dot now moves noticeably slower between stages
2026-07-26
Gave CERT Team Command Structure and Phases of a Crisis the same movement/detail pass as the fire-class animations: both now have a traveling glowing signal pulse running along the connecting lines as each node/phase activates, and a gentle camera swing. Along the way, fixed a real bug: both had originally used a full 360° camera orbit, which spent half the loop staring at the *back* of the flat text labels — Blender's curve-based text only renders correctly from the front, so labels turned blank or mirrored for half the animation. Replaced with a narrow front-facing swing that keeps every label readable throughout. Also backfilled assets/blender/fire-class-a.blend, which was missed in the previous round.
2026-07-26
Replaced the single "5 Classes of Fire" animation with five separate, fully modeled scenes — one per class, each with its own burning material and the correct extinguishing agent:
  • Class A (wood) — water/foam stream
  • Class B (liquid pool fire) — dry-chemical powder cloud
  • Class C (electrical panel, sparking) — CO2 gas mist, distinct horn-nozzle extinguisher
  • Class D (magnesium shavings, white-hot flame) — specialized dry powder, poured on rather than sprayed, yellow canister
  • Class K (frying-pan grease fire) — wet-chemical mist forming a foam blanket over the pan
Each scene has a flickering modeled flame (not a flat glow), rising smoke, and a slowly orbiting camera. A course slide can now carry more than one Visual Aid (all five fire classes point to the same slide), and the transcript embed and course-viewer's diagram button both handle that correctly.
2026-07-26
Reworked Visual Aids navigation and added three animated diagrams:
  • Each diagram now has its own detail page (diagram.html) with the full image or video, complete description, clickable source links, and the exact course slide it illustrates — one destination instead of bouncing between pages
  • A persistent 🖼 Visual Aids button was added to the transcript and course-viewer headers
  • Three new animated diagrams, modeled and rendered in Blender: The 5 Classes of Fire, CERT Team Command Structure, and Phases of a Crisis — looping, muted, autoplaying video that pauses for visitors with "reduce motion" set
  • Note: "Phases of a Crisis" (Impact → Inventory → Rescue → Recovery) replaces the originally-planned "FEMA Disaster Phases" — that 4-phase cycle isn't actually taught in this course; this is what Section 7 covers instead
2026-07-26
Fixed a bug where Search, Transcripts, and the Changelog's source-date table could fail to load ("Couldn't load the transcript data") — they used to fetch() a local JSON file, which browsers block when a page is opened directly instead of through a server. Switched to a plain <script src> data file instead, the same approach the glossary already used. Also redid both Visual Aids diagrams with more color and detail, and reworked the gallery cards: fuller descriptions, a plain-text source citation, and a dedicated button per card instead of a whole-card link.
